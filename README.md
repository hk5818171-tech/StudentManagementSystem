# Student Management System

A console-based Java application for managing student records.

## Features

* Add Student
* View Student
* Search Student
* Update Student
* Delete Student

## Concepts Used

* Classes and Objects
* Constructors
* Encapsulation
* ArrayList
* CRUD Operations
* Method Overriding (toString)
* Menu Driven Programming

## How to Run

1. Compile:
   javac StudentManagementSystem.java

2. Run:
   java StudentManagementSystem
